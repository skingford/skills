# 设计词典 · 12 类 188 词

来源：《Vibe Designing Playbook》设计词典（阿里云设计中心）。原站为可交互词条卡片，此处还原为查表。

**用途**：把「高级」「克制」「自然」这类**形容词**换成词典里的**术语**。形容词模型只能按训练分布的平均值猜；术语带着判据（`Duration: hover ≈150ms 原生，400ms 像在思考`），能直接执行与验收。写 craft.md / design.md 规则、给生成指令、写评审意见时都从这里取词。

用法示例：
- ❌「动效再自然一点」 → ✅「入场用 ease-out 200ms；列表项 stagger 40ms；只动 opacity + transform」
- ❌「这个灰色有点脏」 → ✅「改用 tinted neutral：纯 #808080 像占位符，带轻微色相偏移才像选过的」
- ❌「标签样式统一一下」 → ✅「状态用 Badge（附着、信息性），分类用 Tag（独立、可选、可移除）」

## 01 · Typography 排版

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Kerning | 字偶间距 | 手动调整两个特定字符之间的间距。区别于 tracking（整体均匀调整）。 |
| Tracking | 字间距 | 整段/整词均匀的字母间距。大写标签几乎都需要加宽。 |
| Leading | 行高/行距 | 行与行之间的垂直间距。太紧文字窒息，太松不成段落。 |
| Optical kerning | 视觉字距 | 凭眼睛而非字体内置度量调整间距，消除某些字母对的尴尬缝隙。 |
| Tabular nums | 等宽数字 | 每个数字同宽，列里数字变动仍对齐。价格、统计、刷新数据必用。 |
| Type scale | 字号阶 | 按比例预设、彼此协调的一组字号，保持层级一致。 |
| Weight | 字重 | 笔画粗细。Bold 用于 UI 强调；Italic 用于语义强调或引用，非 UI 层级。 |
| x-height | x 字高 | 小写字母高度。高 x-height 同字号看起来更大。 |
| Cap height | 大写字高 | 大写字母高度。与 x-height 共同决定字体的视觉大小。 |
| Ligature | 连字 | 两字符合并成单一字形以避免碰撞，如 fi、fl。装饰性连字仅用于展示。 |
| Font smoothing | 字体平滑 | 浏览器渲染字体边缘的方式。Mac 上 antialiased 更细更轻。 |
| Text overflow | 文本溢出 | 文字超出容器的处理。省略号截断最常见，用单个 unicode 字符、不切词。 |
| Hyphenation | 连字符断词 | 用连字符把词跨行折断。窄栏/两端对齐有用，最好交给浏览器自动。 |
| Clamp | 流体字号 | 设最小/理想/最大值，字号随断点平滑缩放，无需逐断点声明。 |
| Widow | 孤字 | 段落最后一行只剩一个词。text-wrap: balance 可自动修。 |
| Orphan | 孤行 | 段落首行被孤零零留在新列/新页顶部。常手动修。 |
| Font stack | 字体栈 | 浏览器依次尝试的字体列表。匹配良好的回退字体避免加载时布局抖动。 |
| Line length | 行宽 | 一栏文字宽度。≈65 字符最舒服，太宽眼睛找不到下一行。 |
| Variable font | 可变字体 | 单文件含一组字重/字宽等轴，可无抖动地动画字重、减少文件开销。 |
| Superscript | 上标 | 脚注/指数的升高字符。HTML sup 默认太大、扰乱行距，应手动调。 |
| Subscript | 下标 | 公式/记号的降低字符。HTML sub 同样默认偏大、需手动调。 |

## 02 · Color 色彩

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| sRGB | 标准色彩空间 | 多数屏幕几十年用的标准空间，所有 hex 都在此。色域有限。 |
| P3 | 广色域 | 多数现代屏支持的更宽色域，绿/红更鲜艳，sRGB 达不到。 |
| OKLCH | 感知均匀色彩空间 | 与人眼亮度感知一致。同 lightness 两色看起来真的一样亮。 |
| Alpha | 透明度 | 颜色的透明分量。alpha 边框向后退融进表面，solid hex 坐在上面。 |
| Semantic token | 语义 token | 按用途命名的颜色变量，--color-border-subtle 而非 hex。 |
| Contrast ratio | 对比度 | 前景背景亮度差。WCAG 要求正文 4.5:1、大字/UI 组件 3:1。 |
| Tinted neutral | 带色调中性灰 | 带轻微色相偏移的灰。纯 #808080 像占位符，tinted 才像选过的。 |
| Saturation | 饱和度 | 颜色鲜艳/沉闷程度。暗色模式下满饱和品牌色会刺眼，退 20-30% 更稳。 |
| Chroma | 彩度 | OKLCH 里感知准确的饱和度。浅色调降 chroma（颜色还活），别降 opacity。 |
| Gradient | 渐变 | 两色或多色过渡。HSL/sRGB 中点常发灰，在 OKLCH 里建保持鲜艳。 |
| Opacity vs visibility | 透明 vs 隐藏 | opacity:0 仍占空间、接收点击；visibility:hidden 去交互留空间。 |
| Dark mode | 暗色模式 | 基于暗色表面。最亮的表面应在层级最上。亮色 token 很少能直接套用。 |
| Blending | 混合模式 | 图层与下层的交互。Multiply 变暗、Screen 变亮、Overlay 两者皆有。 |

## 03 · Iconography 图标

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Stroke weight | 描边粗细 | 图标线条粗细。细描边小尺寸消失、大尺寸显单薄，粗细要随尺寸缩放。 |
| Optical centre | 视觉中心 | 看起来居中 vs 数学居中。播放按钮按坐标居中会偏左，往右挪才坐得住。 |
| Filled vs outlined | 填充 vs 描边 | 两种风格传达状态。filled 常表选中/激活，outlined 表默认。混用要有系统。 |
| Cap style | 线帽样式 | 描边端点方圆。多数 UI 里圆头更精致，方头可能显粗糙。 |
| Pixel hinting | 像素微调 | 调整图标路径在小尺寸下对齐像素网格。全细节 logo 在 16px 不调会糊。 |
| Icon library | 图标库 | 同尺寸/粗细/圆角绘制的一套图标。混用两套（即使相似）会累积错配。 |
| Icon size system | 图标尺寸系统 | 图标呈现的预定尺寸（12/16/20/24/48），每档理想上单独绘制而非缩放。 |
| Meaning collision | 语义冲突 | 同一图标在同产品里表两种动作（星=收藏又=评分），用户两个都学不会。 |
| Contextual swap | 情境切换 | 描边↔填充切换表状态变化（激活/选中），约定需全产品一致才有效。 |
| Breathing room | 呼吸间距 | 图标与标签之间的间距。6-8px 起步，是组件设计的一部分而非事后。 |
| Unified weight | 统一权重 | 图标与周围文字视觉权重一致。细描边图标配粗体字像来自不同产品。 |
| Metaphor accuracy | 隐喻准确度 | 图标是否真代表它该代表的。软盘=保存，随受众老化需审视。 |

## 04 · Layout 布局

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Border radius | 圆角 | 内层圆角 = 外层 − padding。两层同值会出现可见缝隙。 |
| Gap | 间隙 | flex/grid 子元素间距，设在父上。不像 margin，末项后无残留空间。 |
| Negative space | 负空间 | 元素周围与之间的留白，定义形状、制造呼吸、引导视线。 |
| Flexbox | 弹性盒 | 行/列排列元素的 CSS 布局模型，控制方向、对齐、间距、伸缩。 |
| Auto layout | 自动布局 | Figma 版 flexbox：元素自动间距、随内容缩放、响应方向与对齐规则。 |
| Layout shift | 布局抖动 | 加载时元素意外移动（图片弹入、字体替换）。预留空间 + 等高回退字体可避。 |
| Overflow | 溢出 | 内容大于容器的处理。hidden 静默裁剪、scroll 加条、auto 按需。 |
| Sticky positioning | 粘性定位 | 滚到阈值后固定。父级设 overflow:hidden 会静默破坏它。 |
| Aspect ratio | 宽高比 | 宽高比例关系。给图片/嵌入设它，浏览器可预留空间防抖动。 |
| Viewport units | 视口单位 | 相对窗口的单位。dvh 考虑移动浏览器 chrome，vh 全屏移动常溢出。 |
| Safe area | 安全区 | 不被刘海/home 指示条遮挡的区域。固定底部元素需考虑它。 |
| Max-width | 最大宽度 | 容器宽度上限。没有它，宽屏上文字行长到读不下去。 |
| Breakpoint | 断点 | 布局切换的点。最好设在内容真正断裂处，而非假设的设备宽度。 |
| Responsive | 响应式 | 适配不同屏幕的设计。流体布局 + 弹性图片 + 断点。Web 的基线期望。 |
| Grid | 栅格 | 组织布局的列系统。12 列是惯例，简单布局 8 列常更好。 |
| Asymmetry | 不对称 | 刻意不等的列/元素。制造张力与趣味。对称稳定但少有趣。 |
| Baseline grid | 基线网格 | 基于正文行高的水平节奏。编辑排版有用，产品 UI 常过度。 |
| Z-index | 层叠顺序 | 同平面元素的堆叠序。弹窗/tooltip/下拉需显式 z-index 否则被裁。 |

## 05 · Interaction 交互

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Affordance | 可供性 | 告诉你怎么用的视觉信号。按钮看着可按，链接看着可点。缺了用户只能猜。 |
| Hover state | 悬停态 | 光标移上的视觉变化，应通过光标变化或颜色确认可交互。仅颜色不够。 |
| Focus state | 聚焦态 | 键盘聚焦的可见指示。删除它是无障碍失败，应换自定义样式而非删。 |
| Active state | 按下态 | 元素被按下的视觉变化。没有它按钮显得无响应，小缩放/变色即可。 |
| Disabled state | 禁用态 | 不可交互元素。仅靠 opacity 不可靠，用专门的 muted token 更可预测。 |
| Cursor | 光标 | 指针图标信号元素行为。pointer=可点、default=静态、text=可选。错了破坏隐式契约。 |
| Pointer events | 指针事件 | 元素能否接收鼠标/触摸。none 让元素可见但不可交互，适合装饰层。 |
| Optimistic update | 乐观更新 | 服务器确认前先更新 UI，感觉即时，失败需回滚。 |
| Debounce | 防抖 | 触发后延迟执行、每次触发重置。阻止搜索框每次按键都请求，300ms 常见。 |
| Touch target | 触控目标 | 可点区域，最小 44×44px。视觉元素可比触控目标小。 |
| Copy to clipboard | 复制到剪贴板 | 复制按钮需可见确认（勾一两秒），否则用户反复点以为失败。 |
| Skip link | 跳过链接 | 视觉隐藏、聚焦时出现，跳到主内容。没它键盘用户每页都要 tab 过导航。 |

## 06 · Motion 动效

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Easing | 缓动 | 动画加减速的速率。ease-out 减速入位自然，ease-in 起步慢显拖沓。 |
| Ease-out | 缓出 | 快起慢落。多数 UI 过渡默认，用于入场。 |
| Ease-in | 缓入 | 慢起快落。用于离场。用在入场会显得勉强。 |
| Ease-in-out | 缓入缓出 | 慢-快-慢。适合屏内位移（开关、卡片滑动），简单进出场则过度。 |
| Stagger | 错峰 | 列表项依次延迟，40ms 有陆续到达感，全部一起像闪一下。 |
| Duration | 时长 | hover ≈150ms 原生，400ms 像在思考，超 400ms 无反馈像坏了。 |
| Transition property | 过渡属性 | 动画哪些属性。animate all 易误伤布局属性致卡顿，opacity+transform 是安全对。 |
| Reduced motion | 减弱动效 | 用户偏好少动画。忽略会引发前庭不适。任何明显位移都要检查。 |
| Skeleton shimmer | 骨架微光 | 扫过骨架屏的移动渐变暗示活动。应尊重 reduced motion。 |
| Spring | 弹簧 | 基于物理弹簧的缓动，轻微过冲后稳定，比标准 ease-out 更鲜活。 |
| Choreography | 编排 | 多元素同时动画的协调。各自乱动是噪音，好编排让眼睛知道看哪。 |
| Enter vs exit asymmetry | 入出场不对称 | 入场是到达该减速、出场是离开该加速。反放入场当出场像倒着来。 |
| Shared axis transition | 共享轴过渡 | 视图间导航的运动方向反映空间关系。前进向右、后退向左。 |
| Motion as feedback | 动效即反馈 | 按钮按下压缩、错误抖动、成功画勾——运动不是装饰，是响应。 |
| GPU compositing | GPU 合成 | opacity/transform 走 GPU、不触发布局重算。animate width/top 强制重排。 |

## 07 · Accessibility 无障碍

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| WCAG | 无障碍指南 | 多数团队的对比度标准。AA 要求正文 4.5:1、大字/UI 组件 3:1。 |
| APCA | 感知对比算法 | 考虑字号字重的新对比模型，比 WCAG 更贴近真实，两者有时不一致。 |
| Screen reader | 屏幕阅读器 | 为盲/低视力用户朗读内容。按 DOM 顺序、标题结构、ARIA 角色导航。 |
| Tab order | Tab 顺序 | 键盘聚焦的移动序列。应遵循阅读顺序，意外跳转常因 DOM 与视觉序不一致。 |
| Prefers color scheme | 配色偏好 | 检测系统主题偏好的媒体查询。尊重暗色模式的正确方式。 |
| aria-label | 无障碍名称 | 给无可见文字元素的可访问名。应描述动作而非元素类型（Search 而非 icon）。 |
| Focus trap | 焦点陷阱 | 把键盘焦点锁在打开的弹窗内，否则焦点会跑到背后页面。 |
| DOM order | DOM 顺序 | HTML 里元素的顺序。屏幕阅读器跟它走、非视觉序。CSS 重排会造成脱节。 |
| Semantic HTML | 语义化 HTML | 用对元素。button 自带键盘/焦点/角色，div 扮按钮要手动补全这些。 |
| Label association | 标签关联 | 用 for/id 把 label 连到 input，否则点 label 不会聚焦字段。 |
| Color-only state | 仅颜色状态 | 仅靠颜色表状态。只用红边框表错误对色盲用户不可见，须配图标/文字。 |

## 08 · Information Architecture 信息架构

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Progressive disclosure | 渐进披露 | 每步只显示所需，深入再揭示复杂。反面是一页堆所有。 |
| Navigation | 导航 | 在产品各区间移动的系统。标签应匹配用户说法、非内部术语。 |
| Mental model | 心智模型 | 用户对运作方式的内在图景。好 IA 匹配它，不匹配用户会迷失并自责。 |
| Hierarchy | 层级 | 元素按重要性排序。没有它一切竞争、无人胜出。 |
| Empty state | 空状态 | 尚无内容时的视图。应解释为何并给下一步，「无数据」终结旅程。 |
| Error state | 错误态 | 失败时显示什么。应说清出了什么错、给具体恢复方式。 |
| Onboarding | 引导上手 | 向新用户介绍产品。最好立即交付价值，完成一个有意义动作比看完导览更易留存。 |
| Confirmation dialog | 确认对话框 | 破坏性/不可逆动作前的提示。应说会失去什么，危险与安全动作视觉拉开。 |
| Wayfinding | 寻路 | 帮用户理解「我在哪、怎么来的、能去哪」的信号系统（面包屑、激活态、标题、URL）。 |
| Signpost | 路标 | 只为定位的 UI（区头、类别标签、步骤指示）。工作时隐形，缺了才被注意。 |
| Labelling | 标签命名 | 导航/区头/类别用词。匹配用户词汇的被用，内部命名的被绕过。 |
| Depth | 层级深度 | 到达内容需穿过的导航层数。3 层是上限，更深需更好寻路或扁平化。 |
| Search as escape hatch | 搜索逃生口 | 用户因导航失败而求助搜索。该可浏览却高搜索量，是 IA 需改进的信号。 |
| Content inventory | 内容清单 | 产品/站点所有内容的完整列表，重构前用以找缺口、重复、孤页。 |
| Card sorting | 卡片分类 | 让用户把主题分成对他们有意义的类别的研究法，构建前验证 IA。 |

## 09 · Copywriting 文案

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Microcopy | 微文案 | 标签、错误、占位符、tooltip 等短 UI 文本，对可信度影响极大。 |
| CTA | 行动召唤 | 主动作的标签。"Save changes" 比 "Submit" 更可信，拥有动作别道歉。 |
| Error message | 错误信息 | 说清出错与修法。"Invalid input" 什么都没说，"邮箱须含 @" 说清一切。 |
| Placeholder | 占位提示 | 输入框内提示，输入即消失。不能替代 label——需要提醒时它已不在。 |
| Sentence case | 句首大写 | 只首词与专名大写。UI 标签默认。Title Case 读起来像法律文件。 |
| Front-loading | 前置关键词 | 最重要的词放最前。"Export ready" 胜过冗长句，用户在扫读。 |
| Inline error | 行内错误 | 紧挨出错字段的错误信息。顶部汇总让用户找，行内才明确。 |
| Voice | 语调（一致） | 所有文字背后一致的个性。正式/随意、技术/朴素，不随情境变。 |
| Tone | 语气（情境） | voice 随情境的调整。引导时鼓励、设置中中性、危险动作旁谨慎。同 voice 不同 register。 |
| Success message | 成功信息 | 动作完成的确认，常被忽略。应具体（"Saved" 非 "Done"）且简短。 |
| Destructive language | 破坏性用词 | 不可撤销动作的文案（删除/移除/吊销）应明确，用 "clear/reset" 软化会误导。 |
| Scannability | 可扫读性 | 为快速读而非细读写。短句、主动语态、关键信息在前。尊重用户注意力。 |
| Truncation strategy | 截断策略 | 溢出时在哪、怎么截。词边界截优于切字符，标题/标签/描述各需自己的逻辑。 |
| Contextual help | 情境帮助 | 在需要的时刻、紧挨它解释的对象旁的说明文字。一句话消除提问需求。 |
| Numeric formatting | 数字格式 | 界面里数字怎么写（1,000 vs 1000；$1.00 vs $1）。一致性比具体约定更重要。 |

## 10 · Tools 工具

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Design system | 设计系统 | 共享的组件、token、模式、指南。最佳状态是活产品而非静态文档。 |
| Source of truth | 真值来源 | 团队设计决策唯一依据。传统是 Figma，越来越多是代码库本身。 |
| Variables | 变量 | 颜色/间距/字号等可复用、从一处更新的命名容器。可扩展系统的基础。 |
| Tokens | token | 存为命名变量、设计工具与代码都能引用的设计决策。让系统跨平台可移植。 |
| Visual language | 视觉语言 | 色/字/形/动/调的连贯决策集，让产品在每个触点都可辨识。 |
| Artboard / Frame | 画板 / 框架 | 设计文件里代表屏/视图/组件的命名画布。Figma 的 frame 还定义裁剪与布局。 |
| Prototype | 原型 | 构建前测试/沟通流程的交互模型。保真度应匹配要回答的问题。 |
| Handoff | 交接 | 设计移交工程的时刻。做好=准确规格+共享 token+设计师可答疑。 |
| Redline / annotation | 标注 | 加在设计上传达意图的测量与注释（间距、token、交互、边界）。 |
| Moodboard | 情绪板 | 提交前探索/沟通方向的视觉参考集，对齐基调与审美。好的在论证。 |
| HiDPI / Retina | 高分屏 | 像素密度 2× 以上的屏。未准备的资产发糊，图标/图/边框需考虑 2×3×。 |
| Open Graph | OG 元数据 | 控制链接分享预览（图/标题/描述）的元数据。常被忽视的第一印象。 |

## 11 · Analysis 分析

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| A/B test | A/B 测试 | 两个变体同时运行比性能。用真实行为而非内部意见验证决策。 |
| Heatmap | 热力图 | 用户点击/滚动位置的可视化。显示什么吸引注意、什么被忽略。 |
| Session recording | 会话录制 | 单个用户会话的录像。精确显示哪里犹豫、困惑、放弃。比热力图更具体。 |
| Funnel | 漏斗 | 用户走向转化目标的路径。任一步流失都是设计问题。 |
| Conversion | 转化 | 访客采取目标动作的时刻。设计通过清晰、信任、减摩擦、CTA 质量影响它。 |
| Bounce rate | 跳出率 | 无任何动作即离开的访客比例。关键页高跳出常指期望与所见不符。 |
| Retention | 留存 | 首访后回来的用户数。强获取也可能差留存，留存更难更重要。 |
| Churn | 流失 | 停止使用的用户。留存的反面。高流失=产品价值不足以留住人。 |
| NPS | 净推荐值 | 用户推荐意愿（0-10）。粗钝但广用，整体满意度的粗略信号。 |
| Scroll depth | 滚动深度 | 用户实际读到页面多深。多数到不了底，折叠下方内容被看到的远少于假设。 |

## 12 · Components 组件

| 术语 | 中文 | 判据 / 定义 |
| --- | --- | --- |
| Button | 按钮 | 主动作触发。需 default/hover/active/focus/disabled/loading 各态。一屏不超一个 primary。 |
| Input | 输入框 | 文本录入。需上方持久 label 而非仅占位符，各态视觉区分。 |
| Textarea | 多行输入 | 多行录入，需与单行同样的状态处理。 |
| Select | 下拉选择 | 从列表选一项。原生可访问但难样式化，自定义需小心键盘与焦点。 |
| Checkbox | 复选框 | 二元选择切换。点 label 应切换，不只点框。 |
| Radio group | 单选组 | 恰选一项的一组选项。区别于可多选的复选框。 |
| Switch | 开关 | 开/关切换，意味即时生效。用于无需保存的设置。 |
| Slider | 滑块 | 在区间内选值。应拖动时实时更新而非仅松手时。 |
| Modal / Dialog | 模态框 | 打断当前流程要求关注的覆盖层。焦点须困在内、背景对屏幕阅读器惰性。 |
| Sheet | 侧拉面板 | 从屏幕边滑入的面板，移动端常用。同模态的焦点与关闭规则。 |
| Drawer | 底部抽屉 | 从底部上拉的 sheet。移动端常替代 dialog。 |
| Popover | 气泡卡 | 锚定元素、点击触发的小覆盖层，可含交互内容（区别于 tooltip）。 |
| Tooltip | 提示框 | 悬停显示的解释小标签，不能含交互内容。要放链接用 popover。 |
| Toast | 轻提示 | 自动消失的临时通知。时长应反映阅读时间而非固定 2 秒。 |
| Badge | 徽标 | 附着在另一元素上的小标签，数字时表计数。带词时行为更像 tag。 |
| Tag | 标签 | 给内容分类的标签，独立、可选、可移除。Badge 是附着的、信息性的——两者不同。 |
| Accordion | 手风琴 | 可展开折叠的堆叠区块。适合 FAQ，不替代需横向对比的 tabs。 |
| Tabs | 标签页 | 在同空间切换相关视图。适合按时间/类别筛同内容，非导航无关区。 |
| Stepper | 步骤器 | 显示序列进度的多步流程。提前显示所有步骤设期望，隐藏制造焦虑。 |
| Carousel | 轮播 | 横向滚动的一行项目。桌面端常是布局没解决的信号，首项获最多注意。 |
| Navigation menu | 导航菜单 | 在主区块间移动的顶层/飞出结构。标签反映用户思维而非构建方式。 |
| Sidebar | 侧边栏 | 锚定边缘的持久导航，仪表盘常用。频繁切区时好用。 |
| Breadcrumb | 面包屑 | 显示层级位置的路径，让深层用户不靠浏览器返回也能回退。 |
| Pagination | 分页 | 在多页内容间移动的控件。列表太长无法一次加载时用，无限滚动是另一权衡。 |
| Skeleton | 骨架屏 | 加载时撑住内容形状的占位，稳定布局、暗示将来。列表/页加载优于 spinner。 |
| Spinner | 加载转圈 | 不确定时长的加载指示。短动作级等待好用，页/列表加载用骨架屏更好。 |
| Avatar | 头像 | 代表用户/实体的小图。图片失败时需回退（首字母或通用图标）。 |
| Card | 卡片 | 分组相关内容的容器。内圆角应小于外、按 padding 算。整面做链接会让文字无法选。 |
| Data table | 数据表 | 行列结构网格。数字应右对齐 + tabular-nums，正确对齐胜过斑马纹补偿。 |
| Combobox | 组合框 | 输入时筛选下拉的输入框，兼具文本框的手感与 select 的约束。 |
| Command menu | 命令面板 | 键盘触发的搜索式导航/执行界面，工具类产品里高级用户避鼠标用。 |
| Progress | 进度条 | 显示确定进程完成度的条。时长未知时用 spinner。 |
| Separator | 分隔线 | 项/区之间的视觉分隔。常在更好的间距能解决时被过度使用。 |
| Empty state | 空状态 | 无内容时的视图。应解释为何并给首个动作，"无结果" 什么都没告诉用户。 |
